# 🧠 Product Review Analysis using LLM & Generative AI

## 📌 Overview

This project focuses on analyzing customer reviews using modern Natural Language Processing (NLP), Large Language Models (LLMs), and Generative AI techniques. It transforms raw review data into meaningful insights through structured processing, sentiment detection, and predictive modeling.

The goal is to understand customer behavior, identify trends, and support data-driven decision-making.

---

## ⚙️ Key Features

### 🔹 Data Preprocessing

* Cleaning text (removing special characters, stop words)
* Tokenization and lemmatization
* Preparing structured data for analysis

### 🔹 Exploratory Data Analysis (EDA)

* Distribution of ratings and review lengths
* Customer demographics (e.g., age groups)
* Product category insights
* Visualization of patterns and trends

### 🔹 Sentiment Analysis

* Classification of reviews into positive, negative, or neutral
* Implementation of machine learning models for sentiment detection

### 🔹 Predictive Modeling

* Use of Linear Discriminant Analysis (LDA)
* Predicting sentiment based on review content
* Identifying hidden relationships in the data

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/srishtiseema/Product review Analysis---LLM-and-GENAI.git
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the Project

* Open the notebook in **Jupyter Notebook** or **Google Colab**
* Execute cells step-by-step for:

  * Data preprocessing
  * EDA
  * Model training and evaluation
